# Mini Task Management Application

A mini task management application built as a study case. It features a FastAPI backend with PostgreSQL and a React frontend.

## Components

- [Backend](./backend/README.md) - Python FastAPI application
- [Frontend](./frontend/README.md) - React TypeScript application

## Technology Stack

- **Backend:** Python, FastAPI, SQLAlchemy, Alembic, PostgreSQL
- **Frontend:** React, TypeScript, Vite
